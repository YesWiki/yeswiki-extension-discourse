# yeswiki-extension-discourse

 - [English](#english)
 - [Français](#français)

## English

[YesWiki](https://yeswiki.net/) extension. Lets a Discourse forum use this wiki's user accounts as its login provider, and opens a forum topic for each new entry of a form.

### Authors

 - all contributors indicated on this page : <https://github.com/YesWiki/yeswiki-extension-discourse/graphs/contributors>

### Install

On your wiki's `/admin/updates` screen, install the `discourse` extension: installing it switches it on. From a shell: `./yeswicli extension:enable discourse`. Version `5.x` is for YesWiki Ectoplasme, `4.x` for Doryphore.

### Usage

Usage help is on your wiki's `/doc` page once the extension is on, and here: https://github.com/YesWiki/yeswiki-extension-discourse/blob/ectoplasme/docs/en/README.md

## Français
